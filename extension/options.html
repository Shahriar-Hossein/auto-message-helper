Teams selectors — adjust if your UI differs

Unread detection uses chatItem for sidebar entries and unread for unread indicators. Each chat must have one visible title and composer, readable message text, and stable message IDs. Authors can be siblings inside each message's own chat-pane-item. Automatic direct-chat sending needs a chat ID from data-chat-id, data-conversation-id, data-thread-id, a Teams route containing 19:, or exactly one immutable participant- key in the chat title. Selected groups can draft and send explicitly without a conversation ID when the title and original message ID, sender, and text still match. The identity selector must select the current chat only.

After saving, open a direct or group chat in Teams and select it in the panel. For groups, choose Selected chat only, then Automatic send or Draft, and Start to monitor new messages; Preview reply creates an immediate draft. Send reply sends a reviewed draft. Automatic send and All unread direct chats are the defaults for direct chats. Start saves monitoring across reloads; Pause turns it off. Generate & send explicitly generates and sends in the selected chat.
